# 公司客户画像与开发优先级

首次使用、换产品或买家方向时读取。本配置针对当前公司的六类3C产品白牌获客，不把其他公司的潜在客户都当作本公司目标。画像、准入和优先级分别判断。

## 先确定本轮画像

- 地区：国家、城市、指定市场/商圈及是否允许当地线上经营主体。配送范围不代替当地经营证据。
- 产品：六类中的本轮子集，必要功能及已知价格带。只找智能眼镜时，蓝牙耳机经营证据不能代替。
- 买家类型：独立批发商、进口商、分销商、市场商户、相关电商卖家、相关零售商；按员工本轮要求取子集。角色应有来源，不因店大就写进口商。
- 经营模式：目标为有证据经营目标白牌商品的独立商家。身份、货品品牌和店名分开。
- 我方约束：仅填写已提供的价格、MOQ、供货方式、产能、定制及认证资料。缺资料标未知；未知不等于不符，不编造能力，也不阻塞能开展的公开研究。
- 可选拓展：数码礼品批发、促销礼品供应商、折扣百货、小型连锁；只有符合本轮买家与目标白牌产品条件才入正式表，否则为拓品待核。

员工无需填技术字段。Codex 将有效配置整理进 task.customer_profile；供货约束是筛选条件，不对外承诺价格或交付。

## 品牌与白牌准入

| 商家分类 | 处理 |
| --- | --- |
| 品牌方 | 排除，包含明确以自主产品品牌运营的品牌公司；不是本轮目标 |
| 官方品牌店 | 排除，包括品牌自营或明确官方身份的店铺 |
| 品牌专卖店 | 排除；明确只经营品牌体系的渠道也不因有联系就纳入 |
| 独立白牌商家 | 有本轮目标产品白牌证据，并满足其他门槛，可准入 |
| 独立混合经营商家 | 同时经营品牌与白牌可保留，但必须有本轮目标产品的具体白牌证据 |
| 身份/品牌模式未知 | 留待核，不能按“没有查到品牌”默认归白牌 |

经营者的店名、网站Logo不自动等于商品品牌。独立商家只销售若干品牌也不能凭店名推断其是官方或专卖，应核具体关系；没有目标白牌证据时仍不能入正式表。自称官方、授权或独家但关系冲突时保留证据和疑点，不凭自称确认授权。

白牌证据应指向该商户具体目标商品：例如正常原文明确标无品牌/通用商品，或可归属商品资料明确说明无品牌供货。无品牌文字仍需核是否与实际商品描述冲突。没写品牌、没露Logo、低价、外形相似、型号通用都只能作追查线索。白牌、接受OEM和有意向采购我方商品分别核实；不能互推。

## 真实性与实际联系

正式客户先满足主体、地域、买家类型、目标产品、白牌及实际联系门槛。事实须绑定可读来源，保留日期与限制；主体或关键归属冲突不进入正式表。公开研究支持“有依据的候选”，不能保证企业履约能力或采购真实性。

电话、邮箱可以是商户公共业务入口。社交、WhatsApp、Zalo、平台聊天和表单须实际观察到商户明示的联系功能或链接，并记录用途和归属。单独网站首页、地址、无法私信的主页、商场管理处和平台客服不能满足商户联系门槛。

来源中明确的采购人或采购申请路径可优先记录；不知道采购人不阻塞合格候选。电话不推WhatsApp/Zalo，看到按钮不代表已发送成功。所有入口保持未试联；历史/失效号码不能冒充现用。

## 准入之后的A/B优先级

先判可开发/待核/排除，再判正式客户的开发优先级。级别不是成交率、信用分或采购规模预测。

- **A重点**：全部准入通过；有实际批发、进口、分销或其他经营能力证据；另有当前可读资料支持持续经营；联系路径清楚。经营能力和持续经营须分别留证，即使来源是同一页也分别解释支持内容。
- **B正常**：已符合准入，但上述经营能力或持续经营证据不足。未知采购量/进口资格不直接写“不具备”；继续正常开发或按缺口补证。
- **待核、排除**：不赋A/B。可以优先研究有希望补齐的对象，但“研究优先”不能伪装成“已合格高价值客户”。

持续经营看实际近期商品/经营活动、可读当前销售资料等，记录内容日期；读取时间不能冒充事件时间，陈年页面、旧缓存或搜索摘要不单独支持当前持续经营。日期未公开则标未知。任务未定时间阈值时不自行设统一90天或180天淘汰线。

不以粉丝量、店面面积、联系方式条数或估算营业额直接评级。平台公开销量须保留平台口径与时间范围，不能改成月销量、进口量或我方预计订单。

运行层按本批证据推导A/B并排序；每次补证重新计算，不能把旧A带给新待核对象。并列保持稳定顺序。人工备注和销售状态不由采集评级覆盖。
