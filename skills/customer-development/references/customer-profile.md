# 公司客户画像与开发优先级

首次使用、换产品或买家方向时读取。本配置针对当前公司的五类主营穿戴及表带产品、两类附带音频产品客户研究，不把其他公司的潜在客户都当作本公司目标。画像、准入和优先级分别判断。工作区保存公司默认画像；新任务继承有效默认，员工本次明确要求只覆盖本任务。继续采集使用明确批次的已保存任务与断点，不从另一任务猜范围。

## 先确定本轮画像

- 地区：国家、城市、指定市场/商圈/地址及是否允许当地线上经营主体，落成明确地域范围。保留地名原文和有证据的别称映射；同国不同城、同城不同市场不能相互替代。配送范围不代替当地经营证据。
- 产品：本轮主线products、附带supplementary_products，必要功能及已知价格带。默认主线为智能眼镜、智能手表、智能手表表带、智能手环、智能戒指；蓝牙耳机、蓝牙音响仅附带。员工明确指定音频专项时按其专项执行，不强加主营五类。
- 买家类型：独立批发商、进口商、分销商、市场商户、相关电商卖家、相关零售商；按员工本轮要求取子集。角色应有来源，不因店大就写进口商。
- 经营模式：目标为有证据经营本轮产品的独立商家；官方品牌店和品牌专卖店独立采集、分表，纯品牌方排除。白牌只作已核／待核标记，身份、商品品牌和店名分开。
- 我方约束：仅填写已提供的价格、MOQ、供货方式、产能、定制及认证资料。缺资料标未知；未知不等于不符，不编造能力，也不阻塞能开展的公开研究。
- 可选拓展：数码礼品批发、促销礼品供应商、折扣百货、小型连锁；只有符合本轮买家与目标产品条件才入正式表，否则为拓品待核。

默认研究顺序为批发商、进口商、分销商、市场商户，再到相关独立零售及电商商户；本轮明确画像覆盖。先按国家、城市／地区、批发市场／批发城、场内商户建立目录，完成当前市场再推进下一市场，不只搜索网页已写OEM的对象。渠道规模不代表单个商户采购规模。

员工无需填技术字段。Codex 将有效配置整理进本轮任务与 task.customer_profile，先保存任务基线再预研。公司产品默认子集及附带范围、买家方向与供货资料可以维护；单次定向产品任务不能把公司长期产品目录缩小。供货资料是研究适配依据，不对外承诺价格或交付。

对已知我方价格、MOQ、供货模式等，分别记录客户条件与判断依据，给出“匹配／未知／冲突”。货币、单位、时间和SKU口径不同先待核，不能直接比较。未知不表示不合格，也不能宣传“适合我方供货”；已确认冲突不进入本任务正式表。员工明确指定的必需条件应逐项满足，尚无证据则待核；不要把所有未知供货资料自动变成必需条件。

## 品牌身份与白牌标记

| 商家分类 | 当前默认处理 |
| --- | --- |
| 纯品牌方 | 有可读证据确认后排除，保留依据 |
| 官方品牌店 | 核实身份并满足其他门槛后放“品牌店”独立表 |
| 品牌专卖店 | 核实身份并满足其他门槛后放“品牌店”独立表 |
| 独立商家 | 有本轮目标产品经营证据且满足其他门槛即可采集，品牌商品或混合经营均可 |
| 经营主体／商家身份未知 | 留待核；不能凭店名、Logo或没有查到品牌关系直接分类 |

白牌标记为已核／待核。“已核”仅指本任务至少一项产品白牌已证实，列对应产品和来源；尚无足够白牌证据为“待核”。目前所读商品均有品牌的，另写实际所见，不从未见推不存在。未查、资料不够或白牌描述冲突均保留待核，不影响其他条件已满足的默认客户资格。

兼容Apple Watch、Huawei等只说明适配，不等于原厂或卖家官方身份，也不单独证明白牌。明确的商品无品牌资料须与卖家和商品对应；低价、无Logo、外形相似和通用型号只作线索。白牌、OEM和采购我方商品分别核实。

旧white_label_required任务仍按原白牌门槛和品牌排除规则评估；明确采用新规则时新建任务，历史资格与冻结交付保留。新默认不会把缺主体、地域、目标产品或联系证据的旧客户自动升级。

## 真实性与实际联系

正式客户先满足主体、地域、买家类型、目标产品及实际联系门槛。事实须绑定可读来源，保留日期与限制；主体或关键归属冲突不进入正式表。公开研究支持“有依据的候选”，不能保证企业履约能力或采购真实性。

电话、邮箱可以是商户公共业务入口。社交、WhatsApp、Zalo、平台聊天和表单须实际观察到商户明示的联系功能或链接，并记录用途和归属。单独网站首页、地址、无法私信的主页、商场管理处和平台客服不能满足商户联系门槛。

来源中明确的采购人或采购申请路径可优先记录；不知道采购人不阻塞合格候选。电话不推WhatsApp/Zalo，看到按钮不代表已发送成功。有一个电话只是准入下限；有已见本地常用消息/官方店铺自链时继续补采。核可见号码与实际href目标是否一致；仅某链接冲突标该入口待核，不抹掉独立证据支持的其他有效联系。所有入口保持未试联；历史/失效号码不能冒充现用。继承的入口保留上次核验日期，并区分本轮已核与历史沿用未复核；旧号的格式变体不是另一条有效新号。

## 准入之后的A/B优先级

先判可开发/待核/排除，再判正式客户的开发优先级。级别不是成交率、信用分或采购规模预测。

- **A重点**：全部准入通过；有实际批发、进口、分销或其他经营能力证据；另有可读资料证明新鲜度窗口内实际发生的经营活动；联系路径清楚。经营能力和持续经营须分别留证，即使来源是同一页也分别解释支持内容。
- **B正常**：已符合准入，但上述经营能力或持续经营证据不足。未知采购量/进口资格不直接写“不具备”；继续正常开发或按缺口补证。
- **待核、排除**：不赋A/B。可以优先研究有希望补齐的对象，但“研究优先”不能伪装成“已合格高价值客户”。

持续经营看实际近期商品/经营活动等，记录活动发生日期；读取时间不能冒充事件时间，陈年页面、旧缓存或搜索摘要不单独支持当前持续经营。日期未公开则标未知，不从“今天能打开”推“今天仍在营业”。自动评A的活动新鲜度默认180天，任务可配置1–730天并保留采用的值；未知日期或超窗只使该证据不能支持A，不据此认定停业或剔除符合准入的B类客户。

不以粉丝量、店面面积、联系方式条数或估算营业额直接评级。平台公开销量须保留平台口径与时间范围，不能改成月销量、进口量或我方预计订单。

运行层按本任务证据推导A/B并排序；每次补证重新计算对应任务资格，不能把旧A带给新待核对象，也不覆盖其他任务的独立结论。并列保持稳定顺序。人工备注和销售状态不由采集评级覆盖。已解决问题显式关闭并保存依据；待核表只展示影响准入的未解决问题；当前默认下“白牌待核”放客户的白牌标记中，不单独阻断资格。

## 业务优先项与证据分级分开

A/B之后另解释四类可证信号：已知供货条件匹配项、同任务目标产品覆盖、本次偏好的买家类型、可归属采购接洽入口。默认不额外假设哪个国家或哪类店更有价值；员工明确偏好时，使用task.business_priorities确定顺序及preferred_buyer_types限定角色偏好。

信号未知保留未知，不按零分解释成低价值；未知采购权限不能从公开销售热线推定。经营规模、实际订单和采购意愿若没有证据仍留给销售核实。业务优先项不豁免准入，不生成成交率或收入预测。
