# 当地渠道与联系生态预研

新地区或范围明显变化时，先保存任务基线，再研究当地可开发渠道和常用商业联系方式，随后采商户。不能先搜到几个商品再补一段地区介绍当作已完成预研。已有同范围资料可复用，保留原检查日期；渠道失效、行政范围变化或产品明显改变时补核相关部分。

## 预研内容

| 类别 | 必须交代 |
| --- | --- |
| 地区和画像 | 现行政范围/传统城区、当地地名、语言、产品子集、买家类型；送货地区不能代替经营地点 |
| 市场/商圈 | 电子数码批发市场、商业街区、批发商场、综合市场相关分区；实际目录、地图或商户入口 |
| 批发进口分销 | 相关企业目录、独立批发商、进口商、分销商；识别销售与采购角色 |
| 商超零售 | 商超、百货、折扣和连锁；区分总部、分店、自营与出租柜台 |
| 电商 | 实际平台及独立商城，商品归属、卖家ID、店铺入口、可见消息功能 |
| 商业社交 | 当地商户公开商业主页、商品帖、自链与可联系入口；不抓群成员当客户 |
| 贸易协会 | 实际可访问的海关/贸易、协会、商会、展会、公开需求；付费源未授权即记受阻或未研究 |
| 联系生态 | 当地目标商户实际公开使用的电话、邮箱、Zalo/WhatsApp、社交消息、店铺聊天等，附适用依据与优先顺序 |

六类路线分别记录applicable、needs_research、blocked或not_applicable。有据不适用与没搜过不同。六类须全部完成初步调查（不能仍有needs_research），并取得可归属本地商户或可靠当地资料支持的实际联系方法后，才开始逐商户采集。blocked须留真实失败尝试和恢复条件，不能把未研究改写为受阻来过关；一个样本只能支持“已观察到”，不能宣传全国最通用。

## 地区目录与市场顺序

1. 按国家→城市／地区→批发市场／批发城→场内商户建目录。国家、城市、市场分别有稳定ID、真实名称和顺序；市场记录来源、真实边界、入口和规模依据。市场群、内部子区和独立市场不能重复冒充。
2. 按[merchant-discovery.md](merchant-discovery.md)先核目标产品和转售渠道适配，再比较有据规模。priority_basis分别说明适配依据、规模依据及未知范围，来源须支持对应事实；“电子市场”或摊位多不能证明穿戴／白牌批发密集。适配待查仍可调查具名入口，不增设先凑合格数的门槛。历史商户数、目录卡、已核主体和合格客户数分开。
3. 每条路线关联当前市场，保存实际入口、分区／页码／游标、已读与未读商户；无目录时查有界街段、地图或公开商户资料，保留实际覆盖限制。线上来源可以核当前市场商户，市场外对象不能强行挂靠。
4. 一次处理一个市场；第一市场完整采集后才进入第二市场。当前市场内路线可并行，主库统一写入。预算用尽、暂缓、受阻或低产不等于市场完成，不能自动跳下一市场。
5. 完成须有真实可核的目录／分区边界及已逐一处理记录，无剩余未读或受阻入口。资料不足以支持全场范围时只报告实际覆盖，继续保留未完成；不能把有限搜索结果当全场商户名单。
6. 商户池先查重、初筛，再补主体、主营、场内归属和实际联系。独立商户无需以白牌证明准入，白牌单独标已核／待核；官方品牌店和专卖店同表分类，纯品牌方排除。

实际计划与检查见[research-progress.md](research-progress.md)。完成一市场不代表全城完成；地区总览保留后续市场及目录未核范围。一份Excel中的一张客户总表，统一主库跨市场查重。

## 联系方式必须完成到可用交接

按地区证据确定优先业务入口，并逐商户读取已发现的官方联系页及官方自链。有一个电话不意味着联系研究结束；存在明确Zalo、WhatsApp、店铺消息或供应商入口时应补采，并记录用途。

显示名称/号码、实际href目标、所属商户与可发起动作分别检查。显示号码与链接目标不同，保留两者和来源，将该入口留待核；其他独立归属的有效电话/邮箱仍可使用。普通电话不推Zalo/WhatsApp；平台客服、网站建设者和市场管理处号码不移给商户。

首选入口要有依据，销售/客服与采购/供应商接洽分开，未核采购人不造姓名。只观察、不试发、不拨号；登录要求和无法读取如实写明。无日期活动、历史号码及缓存产品不能包装成当前采购机会。

## 复用和接续

预研、联系人和市场来源都留实际读取日期。新窗口从项目登记的有效规则和主库恢复，不以聊天摘要重建事实；跨电脑另行共享已授权工作区。已读路线保留，接续仍从当前未完成市场的缺口和未读入口开始。预算到上限交付同一客户总表的阶段结果，并在表头保留当前市场进度，不得将未覆盖改成不适用或自动进入下一市场。跨城后先核新城市的六类渠道和联系生态。
