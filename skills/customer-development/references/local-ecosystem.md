# 当地渠道预研

新国家/城市、明显换产品或接续资料失效时读取。先创建本轮任务和主库基线，再在预研中保存断点。预研由Codex后台执行，员工不需要手工配置平台。目标是先确定最小可用找客路线与当地商业联系习惯，再采具体商家；不要为绘制完整国家地图无限延迟交付。

## 每个地区保存的内容

| 内容 | 需要记录的事实 |
| --- | --- |
| 范围与语言 | 国家、城市/市场、当地产品/批发角色词与常用写法；保留原名 |
| 线下市场图 | 电子批发市场、批发商场、电子商圈、综合市场相关区域、商超百货；真实目录/地图入口 |
| 规模依据 | 有来源的商户数、楼层/市场范围或官方规模描述；没有可比依据则规模未知，不猜大中小 |
| 通信与社交 | 当地目标商户实际展示的电话、邮箱、WhatsApp、Zalo、Telegram、社交私信等；区分平台存在与商户普遍使用 |
| 电商生态 | 当地实际可用平台、平台加卖家ID/实际店铺URL、官方店标签和消息入口；平台域名不作为商户去重键；未知或访问受阻列限制 |
| 其他路线 | 适用的进口记录、行业目录、协会/展会、公开采购及供应商接洽入口 |
| 日期与限制 | 实际检查时间、原资料日期、来源编号、未覆盖与受阻范围；每批保留引用版本 |

不能因一个商户使用某平台就称它是全国最通用平台。平台的国家覆盖和能力可能变化，使用前核当前官方资料及当地商户样本；不把记忆或上个国家的偏好当事实。

## 执行顺序

1. 在已创建的任务中读取已有地区资料与明确范围。国家相同但城市/产品不同，核哪些结论仍适用，不直接照抄市场和商户。
2. 找到有证据的市场/商圈及线上入口。先关注目标白牌产品集中的渠道，再考虑规模和可读性；不固定要求先大型后中型再小型。
3. 选择线下与线上实际可执行路径，记录所选理由及暂不可用渠道，并为本轮各产品建立覆盖格。用户仅指定某个市场时，其他地区只能作单列补充，不计场内成果；周边、线上经营或地址别称须按任务边界另核。
4. 按商品→卖家→经营主体→联系补证；对独立进口商和纯线上商家无需强行绑定某个实体市场。
5. 预研期间即保存来源、可用路线与失败断点，提交时将本轮 region_research 和覆盖结果一起保存。全球任务按实际国家分别建立记录；“全球平台通用”空壳不能支持各国正式客户。

商超研究需区分总部、门店、外包柜台和采购单元。市场管理方只用于获取目录和定位，不作为每家商户的联系。完整商场列表不等于已采完其中商户。

## 预研状态与复用

- **complete**：本轮所需预研已完成，含范围与来源；仅表示本次预研范围，不代表全城或所有平台覆盖。
- **partial**：有真实可用路线，其他渠道未覆盖/不可读。记录具体限制后可沿可执行路线采集，不为等一个付费平台卡住全部任务。
- **blocked**：尚无可用预研证据或完全无法读取。可以整理用户资料、保存待核并交付空正式表，不伪造可用路线。

新正式客户必须有适用于其地区的非blocked预研，同时通过本任务明确城市／市场／地址层级的资格判断。仅有同国预研不能让不同城市或不同市场的商户通过。空市场/通信/电商列表要解释未发现、未查或受阻，不用空列表宣称当地不存在该渠道。无需填满全部渠道清单才能沿已证实可用的路线研究。

历史预研可以复用，但保留真实checked_at及原来源，不把本轮读取本地JSON写成重新访问网页。资料过时、平台规则变化、主体联系冲突时先更新相关部分，不必每轮重复全国调查。跨批沿用已存在来源ID；变更来源内容使用新ID。

## 渠道效果与接续

按本任务产品×计划渠道记录：未搜索、受阻、已搜索无合格结果、有研究结果，配实际尝试次数、证据、发现客户ID与限制。每个目标产品至少有可见覆盖状态；“全部产品”不能用一批耳机客户代替其他五类。不同渠道不要求平均配额，优先安排有实际机会且缺口可解决的路线。

按实际来源记录发现数、重复主体数、净新增主体数、旧主体更新数、正式A/B数、待核数、白牌/主体/联系不符数、失败原因和真实未读入口。有实际记录才计算转化率，分母为本渠道已研究的独立主体，不以搜索结果数充当。多渠道共同发现与补证可以分别归因，跨渠道总新增须按规范主体去重。

优先继续产出合格白牌客户且缺口可解决的路径。低产来源应区分目标不匹配、已重复覆盖、访问失败、地区资料不适用；不以单次零新增声称市场枯竭。下次行动关联未解决问题、已尝试次数和触发条件；页面仍被同一限制阻挡且没有新条件时不重复空转。补齐问题后显式关闭，保留历史尝试，接续只处理仍开放且可执行的事项。

这些预研和覆盖信息保存在用户工作区与批次，Excel采集说明仅呈现必要范围和限制，员工不需要看技术日志。完整字段见[data-contract.md](data-contract.md)，具体来源操作见[sources.md](sources.md)。
