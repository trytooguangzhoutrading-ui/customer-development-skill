# 市场适配与商户发现

新选市场、当前市场长期低产或员工质疑名单质量时读取。目的在于找到相关经营主体并持续补证；搜索次数、档案行数和规则检查通过都不是客户开发成果。

## 先分清市场规模与产品适配

“电子市场”“数千摊位”只说明市场名称或总体规模，不证明智能穿戴、手机配件成品或白牌批发商密集。先读市场实际分区及具名商户的经营资料，分别记录成品数码／手机配件、电子元件／维修、音频等已观察类别；目标产品与转售角色须分别有依据。少数样本只代表已观察入口，不推算全场比例，也不从未找到推断全场没有。

新市场排序先看目标产品和买家角色的实际适配，再比较有据规模。尚不清楚时写“适配待查”，仍可发现具名商户；不要额外要求先找到若干合格客户才能开始调查。已锁定市场如主要命中其他行业，应复核该市场的相关分区、边界和发现来源，并保存适配判断、证据、未知范围及下一入口。

若剩余路线只能反复返回不相关商户或不可访问来源，记录“市场适配待复核／可访问范围不足”，保留未完成和真实断点；报告需要调整的范围及理由。未经用户明确调整，不进入其他市场；不能把调整优先级写成原市场采完，也不能为了坚持市场顺序重复无效搜索。

## 以商户入口展开，不以搜索结果页充目录

选择当前市场真实可读的入口：市场商户目录／楼层图、地图商户卡、公开商业主页及商品帖、平台卖家目录、可辨认店名和柜号的市场巡店资料。按楼栋、分区、街段、分页或已见游标记录已读边界和下一入口。每次读取尽量提取该页全部相关具名商户，再分别回到商户资料；没有读到的卡片不能算处理完成。

当地词分别组合产品、转售角色与位置。例如越南可用 đồng hồ thông minh、phụ kiện điện thoại、bán sỉ、nguồn hàng、giá sỉ，再结合实际市场名或街段。词表只是发现方法，命中不等于商品、批发或场内已核；不强加 OEM／No Brand 关键词，也不只寻找拥有官网的商户。能读商业帖、店铺商品、地图业务号的来源同样可用。

搜索用于定位具体入口。若换词仍返回同一篇排名文章、同一批元件店或同一旧帖，记录命中重合并结束这条搜索路线，改读已见商户卡、相关分区或另一种可用来源；没有实际新入口就说明限制，不编造分页、接口、柜号或目录完整性。受限社交页可保留入口并换正常公开来源，不能把搜索摘要写成已读商业帖。

同市场并行时共享已读／已派发入口，以实际URL或查询加页码／游标区分；重复领取先复用回执，只有新增内容或恢复条件才再读。按真实分区或不同来源分工，不先把80次平均分完再各自重复搜。发现明显不相关的业务时先记录观察，把后续投入转向相关商户，不继续为它补齐所有联系方式。

## 商户池分层，保留线索不等于计作有效客户

| 层次 | 保存与计数 |
| --- | --- |
| 正式客户 | 主体、地域、买家角色、至少一项目标产品经营、实际联系及去重通过；白牌可待核。品牌店同表标类型。 |
| 渠道储备 | 已有可归属商业资料证明是相关成品3C／手机配件转售渠道，但目标产品尚缺证；写实际相关性与待补事实，不计正式客户。 |
| 待核线索 | 有目标产品或相关转售渠道线索，但主体、地址、联系或来源尚需核实；保留明确入口与缺口。 |
| 目录观察 | 只见电阻、线路板、LED维修件、普通电池等，且没有通向目标成品或相关转售渠道的依据；或仅有无法归属的陈年店名。留在市场研究记录供覆盖与追查，不凭“电子”二字计渠道储备或扩大客户总数。 |

旧档案不删除、不改写旧交付。新一轮展示按本轮证据分层；有目标线索的历史商户可待核，单独标历史日期，不能按重新发现计新主体。目录观察若后来出现相关成品渠道或目标产品资料，可升级为线索并继续查重。

产品经营证据可来自可归属的商品卡、商户商品帖／目录、清晰的店铺销售图片／视频或可靠第三方原文。不要求自有网站、税号、独立详情页或型号编号；须能明确识别其实际销售的目标产品，空分类、泛广告、模糊图片不算。缺品牌、MOQ、采购负责人或白牌证明不阻挡已满足其他准入的独立商户。

## 发现与补证的反馈

每完成一个真实入口／分区，检查：新发现的相关主体、目标产品已证主体、可归属联系、历史重复、不相关观察、关键补证改变及未读边界。优先读取能引出新相关商户的入口，并对有希望晋级的商户补决定性事实；不把整轮耗在少数旧客户的重复主页或非必需白牌、OEM资料上。不设统一发现比例、商户配额或最低白牌占比。

低产应说明是市场适配未知、发现入口未展开、来源受阻、重复历史、相关渠道待产品补证，还是其他必需事实不足。各原因对应下一动作；只有预算耗尽不构成分析。80次／45分钟是默认上限，无效路线应提前调整，不为用满次数继续重复。

交付先报告本轮新增正式主体、旧线索晋级、相关渠道储备和待核线索，再列历史更新与累计规模。历史复核的正式客户不能写成新增客户；目录观察数量单列研究日志，不混入客户总数。单一客户总表仍按一个主体一行、实际地域和类型筛选。
